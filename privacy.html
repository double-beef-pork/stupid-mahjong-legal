ほとんどの対局では、手牌は端末の外に出ない

通常の上がり判定は、端末に入っている意味辞書だけで終わります。この経路では、当方のサーバへ手牌も異議文も送りません。

設定（精密再判定の同意、画質など）は、原則として端末内に保存します。Steam Cloud への同期は将来の話で、今は「端末の中」として扱います。

外へ出るのは、精密再判定と「ちょっとまったー」だけ

次のときだけ、卓のホスト機が当方の HTTPS 判定プロキシへデータを送ります。どちらも、タイトルで一度同意したプレイヤーに限ります。

  • 1000 点の精密再判定
  • 他家の「ちょっとまったー」異議と、そのあとの反論

送る内容は次のとおりです。

  • 手牌のラベル（かな・国名など、画面に出る識別子）
  • 局のテーマ ID（ひらがな / 国旗など）
  • 異議・反論のテキスト
  • Steam のセッショントicket（アカウント単位の日次上限を数える認証用）

意図して送らないものは次のとおりです。

  • Steam 表示名、プロフィール、アバター
  • キャラクター外見の詳細
  • マイク音声やチャットログ（本ゲームにボイス／テキストチャットはない）
  • 住所、電話、決済情報（決済は Steam 側）
  • 広告 ID や、当方が発行する端末フィンガープリント

HTTPS でつなぐ以上、接続先のアクセスログには IP アドレスや日時など一般的な接続情報が残り得ます。それを解析 SDK の行動追跡には使いません。

同意しなくても遊べる。あとからオフにもできる

タイトル初回で、外部の判定サーバ（と、その先の国外サービス）を使うか聞きます。断っても、辞書判定の対局はそのままできます。設定の「精密再判定に外部AIを使う」で後から変えられます。

オフのクライアントでは、精密再判定は始まらず、1000 点も減りません。異議文もプロキシに乗りません。

何のために使うか

送ったデータと運用ログの用途は、次に限ります。

  • 精密再判定・異議の解釈（役名と短い理由の補助）をゲームへ返す
  • Steam チケット検証と、Steam アカウントあたり UTC 日次 40 回の上限管理
  • 障害調査・濫用防止のための短い運用ログ（手牌本文やプロンプト全文は残さない方針）
  • 法令対応、権利侵害への対応

広告配信や、第三者への販売には使いません。

判定の途中で触る外部サービス

精密再判定の経路では、次を使います。ゲームの EXE が OpenAI を直接呼ぶことはありません。

サービス役割補足
Fly.io判定プロキシの置き場（優先リージョン nrt＝東京）会社は米国。マシンは日本を優先するが、制御側は国外にまたがり得る
OpenAI（API）文言の解釈米国など。API では顧客コンテンツを学習に使わない契約を前提にする。濫用監視などで最大おおよそ 30 日残ることがある。Zero Data Retention が取れれば使うが、必須ではない
Valve（Steam Web API）セッショントicket の検証米国。Steam アカウント本体は Valve のプライバシーポリシー

GitHub / GitHub Pages は、この文書の公開用です。手牌やチケットは置きません。

委託や処理に必要な範囲だけ渡し、監督に努めます。

国外を通ることがある

精密再判定を使うと、データは日本国外（OpenAI・Valve・Fly.io のインフラなど）でも扱われ得ます。各国の制度は日本と同じではありません。

当方がやっていることは次です。

  • 通信は HTTPS
  • プレイヤー向け EXE に OpenAI の API キーを入れない
  • 運用ログからプロンプト本文・手牌本文・キーを外す方針
  • 日次上限とチケット検証で濫用を抑える

制度の全文比較はここには書きません。各社の公開資料（OpenAI の API data controls、Steam Privacy Policy、Fly.io の文書）を見てください。

どれくらい残すか

種類方針
プロキシの運用ログ（request id、SteamID のハッシュ、HTTP 状態、token 概数など）最大 14 日を目安に削除。本文・手牌・キーは残さない
OpenAI 側先方の既定（濫用監視などで最大おおよそ 30 日など）。ZDR ならその条件
端末の同意・設定アンインストールや設定変更まで
アクセスログ（IP など）ホスティング側の既定。長期の人物プロファイリングには使わない

法令で長く残す必要があれば、その限りではありません。

売らない。渡すのは委託と法令のとき

送信データを広告ネットワークに売ったり渡しません。例外は次です。

  • 上に書いた委託・処理
  • 本人の同意があるとき
  • 法令に基づくとき
  • 生命・身体・財産の保護に必要で、同意が難しいとき

Steam Overlay の通報など Valve の機能は、Valve の仕組みに従います。

安全管理（できる範囲）

  • 秘密鍵をクライアントに焼かない（公開 URL と Steam ticket）
  • HTTPS
  • サーバ権限の限定と、余計なログ項目の抑制
  • 日次上限とチケット検証
  • Unity Analytics、第三者クラッシュレポーター、独自 BAN サーバは入れない（いまの方針）

万全とは限りません。侵害が分かったときは、法令に従って知らせ、対応します。

解析・広告・人生を決める自動処理はない

Unity Analytics や広告 ID 追跡 SDK は入れていません。テレメトリはプロキシの運用ログ以外にありません。

Live AI の出力は役の提案の補助です。決済や雇用のような法的効果を自動で決めるものではありません。卓の進行はゲームルールとホストの権威に従います。

表示前にゲーム側でフィルタを通し、違法な内容や、Steam が Live-Generated で禁じる Adult Only Sexual Content などを落とすよう努めます。取りこぼしはあり得ます。

年齢ゲートはゲーム内にない

レーティングは Steam Content Survey に従います。保護者は、お子様が精密再判定（外部送信）に同意しない設定にできることを確認してください。
