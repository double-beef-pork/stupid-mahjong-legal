連絡先

サポートは Steam コミュニティのディスカッション のみです。メールアドレスは公開しません。

外部へ送るデータ（Live AI）

通常の初回上がり判定は端末内の意味辞書だけで完結し、外部へ送りません。

次のときだけ、ホスト機が開発者の HTTPS 判定プロキシへ送ります。

  • 1000点の精密再判定
  • 他家の「ちょっとまったー」異議（および続く反論）

送るもの:

  • 手牌のラベル（かな / 国名など）
  • 局のテーマ ID
  • 異議・反論のテキスト
  • 認証用の Steam セッショントicket（プロキシがアカウント単位の日次上限を数えるため）

送らないもの:

  • プレイヤー名、見た目、Steam 表示名、顔写真
  • ゲームが意図して付与する IP や端末識別子（一般的な HTTPS 接続のネットワーク情報はプロキシ／ホスティング側のアクセスログに残り得る）

タイトル初回で同意を求めます。拒否しても通常の辞書判定で遊べます。設定から後で変更できます。

保持

  • プロキシの運用ログ（request id、SteamID のハッシュ、HTTP status、token 数）: 最大 14 日。プロンプト本文・手牌・API キーは残しません。
  • OpenAI API 側の保持は提供者の既定（最大約 30 日）に従います。Zero Data Retention が取れれば利用しますが必須ではありません。

課金と上限

精密再判定の外部呼び出しは開発者負担です。Steam アカウントあたり UTC 日次 40 回を超えると辞書のみになり、「本日の精密判定の上限に達しました。」と表示します。

解析

Unity Analytics、クラッシュレポーター、その他の解析 SDK は入れません。プロキシの運用ログ以外のテレメトリはありません。

Steam Overlay

Steam Overlay（Shift+Tab）および Valve が提供する通報手段をゲーム側で無効化しません。
