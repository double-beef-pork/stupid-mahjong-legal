3. 収集する情報と収集しない情報

3.1 通常プレイ（辞書判定のみ）

通常の初回上がり判定は、端末内の意味辞書だけで完結します。この経路では当方が運営するサーバへ手牌や異議文を送りません。

端末上の設定（例: 精密再判定への同意 ON/OFF、画質など）は、原則として端末内の PlayerPrefs 等に保存されます。Steam Cloud への同期は将来機能（ロードマップ上）であり、有効化するまでは本ポリシー上「端末内」として扱います。

3.2 精密再判定・異議（Live AI）— 同意が必要

次のときだけ、ホスト機が当方の HTTPS 判定プロキシへデータを送ります。

  • 1000 点の精密再判定（SelfRejudge）
  • 他家の「ちょっとまったー」異議および続く反論

送るもの（送信データ）

  • 手牌のラベル（かな・国名など、ゲーム内表示に使う識別子）
  • 局のテーマ ID（例: ひらがな / 国旗）
  • 異議・反論として入力されたテキスト
  • 認証用の Steam セッショントicket（プロキシが Steam アカウント単位の日次上限を数えるため）

送らないもの（意図的に含めない）

  • Steam 表示名、プロフィール文、アバター画像
  • キャラクター外見の詳細データ
  • マイク音声、チャット全文ログ（本ゲームはボイス／テキストチャットを提供しません）
  • 住所、電話番号、決済情報（決済は Steam が処理）
  • 端末の広告 ID や、当方が発行する独自の端末フィンガープリント

ネットワーク上避けられない情報

HTTPS 接続の性質上、プロキシ／ホスティング側のアクセスログには、一般的な接続メタデータ（IP アドレス、日時、User-Agent 相当、TLS 関連情報など）が残り得ます。当方はこれを解析 SDK による行動追跡には使いません（後述）。

3.3 同意の取得と撤回

タイトル初回に、精密再判定・異議で外部 AI を使うことへの同意を求めます。拒否しても、辞書判定による通常プレイはできます。設定の「精密再判定に外部AIを使う」から後で変更できます。

同意しない／撤回したクライアントでは、精密再判定は開始されず 1000 点も消費されません。異議理由もプロキシに乗りません。

Steam チケット検証や OpenAI API 呼び出しなど、国外の事業者を経由する処理が含まれるため、精密再判定を使う場合は 本ポリシーに記載の国外への取扱いを含むことへの同意 をお願いします（同意 UI および本ページ）。

4. 利用目的

当方が送信データおよび運用ログを取り扱う目的は次に限ります。

  • 精密再判定・異議の文言解釈（役名と短い理由の生成補助）およびその結果をゲームに返すこと
  • Steam チケット検証による不正利用防止、および Steam アカウント単位の UTC 日次呼び出し上限（現行 40 回）の管理
  • 障害調査・濫用防止のための最小限の運用ログ（手牌本文やプロンプト全文は残さない方針）
  • 法令に基づく対応、権利侵害への対応

広告配信、スコアの信用調査、第三者への販売目的では使いません。

6. 国外での取扱い

精密再判定を利用する場合、送信データおよび関連ログは、日本国外（少なくとも米国に本社を置く OpenAI / Valve、ならびに Fly.io のインフラ）で取り扱われ得ます。

外国の個人情報保護制度は日本と同一ではありません。当方は次の安全管理に努めます。

  • 通信は HTTPS で暗号化
  • プレイヤー向け EXE に OpenAI API キーを埋め込まない
  • プロキシの運用ログからプロンプト本文・手牌本文・API キーを排除する方針
  • 日次上限とチケット検証による濫用抑制

詳細な制度比較の全文は本ポリシーに掲載しきれないため、各社の公表資料（OpenAI API data controls、Steam Privacy Policy、Fly.io のドキュメント等）も参照してください。

8. 第三者提供

次の場合を除き、送信データを第三者に「販売」したり、広告ネットワークに渡したりしません。

  • 第 5 節の委託・処理の範囲
  • 本人の同意がある場合
  • 法令に基づく場合
  • 人の生命・身体・財産の保護のために必要で、本人同意が困難な場合

Steam Overlay 経由の通報など、Valve が提供する機能は Valve の仕組みに従います。

9. 安全管理措置（概要）

  • クライアントに秘密鍵を焼かない（Player は公開プロキシ URL + Steam ticket）
  • 転送時暗号化（HTTPS）
  • 権限を限定したサーバ設定、不要なログ項目の抑制
  • 日次キャップとチケット検証
  • 解析 SDK・クラッシュレポーター・独自 BAN サーバを入れない（現行方針）

完全なセキュリティは保証できません。侵害が判明した場合は、法令に従い必要な周知・対応に努めます。

10. 未成年者

本ゲームにゲーム内年齢ゲートは置きません。レーティングは Steam Content Survey に従います。保護者の方は、お子様が精密再判定（外部送信）に同意しない設定にできることをご確認ください。

11. 解析・広告・自動意思決定

  • Unity Analytics、第三者クラッシュレポーター、広告 ID ベースの追跡 SDK は入れません
  • プロキシ運用ログ以外のテレメトリはありません
  • Live AI の出力は役の提案補助であり、クレジット決済や雇用等の法的効果を伴う自動意思決定ではありません。最終的な卓の進行はゲームルールとホスト権威に従います
  • 出力にはゲーム側のフィルタを通し、違法・Steam が禁止する Live-Generated Adult Only Sexual Content 等を表示前に落とすよう努めます（完全排除は保証しません）

12. 開示等の請求、同意撤回

Steam コミュニティのディスカッションから請求できます。

  • 同意の撤回: ゲーム内設定で外部 AI 利用をオフ
  • 端末内設定の消去: アプリ削除や設定リセット
  • サーバ側ログ: ハッシュ化された識別子と短い保持のため、特定個人への全ログの完全消去対応には限界があります。可能な範囲で対応方針を回答します
